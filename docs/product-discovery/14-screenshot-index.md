# 14 — Screenshot index

Captured 2026-11-05 from a local build of `main` connected to the project database, using the synthetic **"ZZ Rehearsal Gym"** test gym and test logins (owner, athlete). No real customer data. No invite, reset or kiosk-setup links were opened, so no secrets appear. Next.js's development badge was hidden. Full-page captures.

Viewports: **desktop 1440×1000**, **mobile 390×844** (web app). The native mobile app was rendered with Expo's web mode at 390×844 (device pixel ratio 3, so images are 1170 px wide).

**Known caveats:** belt colours don't render (defect, see `02-feature-inventory.md`); some test member names carry numeric suffixes; data volumes are small.

## Not captured, and why

- **Family (parent) view:** no parent test login exists in the rehearsal gym; creating one would modify production data.
- **Kiosk in use, sign-up link page, invite claim page, password reset page:** these need live secret tokens or device cookies.
- **Tagging player with video, share card image, push notifications, in-app recording:** they need a video file, a real device or a native build.
- **Public share page:** no share link exists in the rehearsal gym.
- **Mobile app on a real device:** never built for iOS or Android.
